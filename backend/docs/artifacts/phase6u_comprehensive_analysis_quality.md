# Phase 6U-P4 Comprehensive Analysis Quality

## Summary

This phase hardens `ComprehensiveAnalysisCoordinator` as a closed-evidence synthesis layer. The comprehensive LLM now receives structured subreport summaries instead of full Markdown reports, and final output passes post-validation for unsupported numbers, identity, forbidden content, source scope, limitation retention, and duplicate paragraphs.

## Real Input Audit

- Technical report: generated by `TechnicalAnalystAgent.analyze()` in sync/scoped paths and kept in `sections["technical"]`.
- Fundamental report: generated by `FundamentalAnalystAgent.analyze()` and kept in `sections["fundamental"]`.
- News report: generated by `NewsAnalystAgent.analyze(..., hours_back=72, limit=10)` and kept in `sections["news"]`.
- Peer comparison report: generated by `PeerComparisonAnalystAgent.analyze()` or `analyze_async()` and kept in `sections["peer_comparison"]`.
- `market` and `symbol`: normalized/returned by `analyze`, `analyze_async`, and `analyze_scoped`.
- `stock_name`: fetched only in async/scoped paths and returned as `stock_name`; sync `analyze` remains `market/symbol`.
- Timeout/failure: each sub-agent has `_AGENT_TIMEOUT = 300`; failed/timeout sections are retained as unavailable section text and metadata status.
- Sections schema: raw subreports remain under `technical`, `fundamental`, `peer_comparison`, `news`.
- Final report schema: `report` remains Markdown; `metadata` adds only `partial` and `synthesis_validation`.
