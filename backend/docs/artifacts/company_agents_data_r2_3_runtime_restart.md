## Root Cause: Backend Startup Validation

**File:** `backend/app/core/startup_validation.py`  
**Trigger:** `APP_ENV=production` (set by `docker-compose.yml` `environment:` override)  
**Behavior:** Fail-fast — refuses to start if production security requirements unmet.

The validation fires when `APP_ENV in {"staging", "production"}`. The root `.env` sets `APP_ENV=development` but `docker-compose.yml` overrides it with `APP_ENV=production` in the `environment:` block.

### Failing Checks (4 errors)

```
ValueError: [startup_validation] Configuration errors for environment 'production':
  • EMAIL_VERIFICATION_HMAC_SECRET is not set.
    Generate a random 32+ byte value and set it as an environment variable.
  • EMAIL_VERIFICATION_REQUIRED must be True in staging/production.
    Set EMAIL_VERIFICATION_REQUIRED=true in your environment.
  • EMAIL_PROVIDER=fake is not allowed in staging/production.
    Set EMAIL_PROVIDER=resend or EMAIL_PROVIDER=sendgrid.
  • INVITE_CODE_HMAC_SECRET is not set.
    Generate a random 32+ byte value (distinct from all other secrets).
```
