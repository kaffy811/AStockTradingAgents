# HKNA 产品验收报告 5：P0/P1/P2 重新排序

## 1. 当前判断

P0 尚未完成。14 条 numeric-invalid 历史样本缺少可追溯的 S0–S8 内容，不能安全修复任何 D1–D7 类别。当前应先补齐 trace durability，而非调整数字规则。

## 2. 重新排序

### P0-A：失败 trace durability

在每个 Agent 阶段原子持久化审计快照；失败、超时、空响应和质量门拒绝也必须记录。该能力须默认脱敏、受配置控制且不能影响用户回答。

### P0-B：纯提交 release image

用独立 worktree / 可追溯 image tag 建立与 Git SHA 一一对应的候选镜像。既有 dirty dependency 和 warmup 改动不得混入。

### P0-C：仅修复已证实的数字根因

新 trace 样本形成主导根因后，单独授权最小修复与回归。

### P1：Agent Chat V1

P0 关闭后推进意图路由、来源引用、状态表达、用户反馈和研究闭环。用户界面只呈现一个研究助手，内部 Agent 负责事实检索、分析、审阅和安全发布。

### P2：增强研究能力

横向比较、行业主题、组合摘要、个性化提醒和多模型成本优化均在基础可信度与网站闭环稳定后实施。

## 3. 发布建议

当前维持 `HOLD_1_PERCENT`。P1/P2 可以完成 PRD 与原型准备，但不得在 P0 未通过前进入生产扩流或混入 P0 发布候选。
