# HKNA 产品验收报告 8

## 1. 本次验收范围

仅验收 TradingAgents 既有新闻、公告、热点、行业与个股资讯的来源治理和 Agent 复用边界；未运行 Provider，未改业务代码。详细证据见 Phase 7C0 三份审计交付物。

## 2. 已完成内容盘点

- 个股新闻 REST/Agent 链路已实现，但真实上游为 AKShare → 东方财富公开网页关键词搜索。
- 行业/主题/市场关键词新闻工具已实现，但并非独立行业新闻源。
- CNINFO 官方公告/报告发现、字段标准化、URL 白名单与 `report_documents` 持久化链路已实现。
- Tushare forecast/express 已封装；Tushare news 未实现且保持 permission denied。

## 3. 数据验收

### 3.1 新闻数据

- 数据内容：个股与任意关键词新闻标题、摘要、来源、时间，部分链路带 URL。
- 数据来源：AKShare 封装的东方财富网页搜索。
- 获取或运行方式：请求时 live 调用；个股链路仅短 TTL 缓存。
- 当前状态：技术可调用，来源未批准。
- 当前可用性：只能作为研究线索，不能作为最终用户新闻事实。
- 主要问题：无唯一 ID、as_of、条款状态和可靠匹配依据；行业词共现不等于行业或供应链关系。

### 3.2 股票数据

- 本轮不验收行情正确性。行业热门股存在独立数据库快照模型，但它是行情热度，不是新闻快照。

## 4. 功能验收

- 功能/模块：CNINFO 官方公告/报告
- 当前作用：发现并持久化官方定期报告。
- 当前状态：已实现。
- 是否可用：可用于官方公告/报告事实。
- 当前价值：唯一符合本轮 approved 规则的既有来源。
- 主要缺口或风险：缺显式 terms_status/as_of；不能扩展为通用新闻。

- 功能/模块：个股/行业/主题/市场新闻 Agent 工具
- 当前作用：通过关键词搜索获取网页新闻。
- 当前状态：已实现但来源治理不合格。
- 是否可用：仅研究线索。
- 当前价值：候选发现。
- 主要缺口或风险：当前会进入 LLM 上下文，存在被输出为事实的风险。

## 5. 当前产品阶段判断

新闻功能处于“技术链路存在、来源审批与事实治理未完成”阶段；官方公告链路可用，通用新闻不可生产复用。

## 6. 下一步任务部署

- P0：Owner 审批新闻 Provider；无批准行业源时统一返回 `unavailable`。
- P0：隔离 `research_only` 数据，禁止进入最终事实输出。
- P1：建立持久化新闻快照与完整来源字段。
- P1：修正 Agent 来源等级与 fail-closed 路由。
- P2：在批准来源基础上建设行业/主题关系证据模型。

## 7. 注意事项

- 不得把个股新闻接口用于行业新闻。
- 不得用关键词共现证明“直接受益”或供应链关系。
- Tushare news 保持 permission denied，本阶段不购买、不接入。
- 当前验收状态为 `EXISTING_NEWS_SOURCE_APPROVAL_REQUIRED`。
