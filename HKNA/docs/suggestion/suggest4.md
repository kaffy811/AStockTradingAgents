# HKNA 产品验收报告 4：可交付金融 AI 产品路线

## 1. 当前阶段

项目处于受控 1% Canary。年报 RAG、报告年份选择和引用元数据隔离已有验证，但数字校验失败率和运行镜像可追溯性仍阻止扩流。

## 2. 产品定位

TradingAgents 应定位为“有可追溯证据的中国股票研究助手”，帮助用户理解财报、行情、事件与风险；不提供买卖建议或收益承诺。

## 3. 交付前的主链路

用户搜索或输入问题 → 确认公司/市场/期间 → Agent 检索可用证据 → 输出带来源、数据状态和风险边界的分析 → 用户继续追问、比较、收藏或加入自选。

## 4. 推荐路线

1. 可信度与发布基线：先关闭数字失败归因、纯 commit 镜像和 1% 可观测性。
2. Agent Chat V1：建立统一意图路由、研究执行、引用审阅和面向用户的降级状态。
3. 网站研究闭环：完善首页、搜索、股票页、报告页、会话页、自选与历史记录。
4. 数据与运营能力：覆盖数据新鲜度、任务失败、管理员追踪、用户反馈和审计。
5. Beta 到正式交付：真实用户验收、性能/安全/合规测试、灰度扩流与运营手册。

## 5. Agent 产品边界

对用户只呈现一个研究助手；系统内部可按事实检索、财报分析、行情技术面、新闻事件、引用审阅和安全发布分工。任何 Agent 都不得绕过事实、引用、数值与最终质量门。

## 6. 发布建议

在完成数字可信度修复、镜像可追溯性和连续观察前，维持 `HOLD_1_PERCENT`。不应为扩流先添加更多 Agent 功能。
