# 新手报告：本地实现与验收

本次目标是“只解读已取得的数据，默认适合 A 股新手阅读”，不是补齐全部上游数据。

## 产品行为

- 默认 REPORT_READER_MODE=beginner；standard 保留原有标准报告路径以兼容旧消费者。
- 只写有事实依据的内容，不生成空章节、不列 PE/PB 等缺失清单，不把数据获取问题评价成公司问题。
- 空财务、空新闻、报告期未知或不同的同行会跳过对应模型解读。真实模型故障仍在元数据记录，未伪装为成功。
- 默认短篇白话，少缩写，解释必要术语；禁止目标价、买卖指令、未来涨跌推演和过度概括公司整体情况。
- 默认报告放在页面最前；覆盖评分不再显示，生成记录、详细股价图、行业快照和分项解读按需展开。
- 历史页重开不再重复展开全部专业执行信息。修复历史 API 将独立存储的 agents/warnings 合并回报告元数据。

## 图表来源与边界

- 股价线图只用技术分析此次取到的最近最多 30 根 K 线；收入/净利润同比条形图只用基本面此次取得的增长字段与报告期。
- ContextVar 在每次工作线程调用里独立收集，图表不从模型文字猜数、不增加数据请求、不跨股票混用。
- visuals 随 metadata 保存；历史重开使用保存的数字与日期，不替换成今天行情。无数据的图卡不渲染，不画零值占位；真实 0 保留。
- 延续既有数字/凭据输出保护，整句移除未获支持的数字声明。额外支持证据中负百分数的等价“下跌3%”写法和等价中文日期，不全局放开无符号数字，错误“上涨3%”仍被拒绝。
- 预览截图仅使用用户粘贴报告中的已知事实（收入 +2.42%、利润 +2.21%、报告期 2026-09-30），不代表重新获取的市场数据。未编造缺失的价格序列用于预览。

## 手动验收

刷新 http://localhost:3000 并重新生成报告。若需中文，请在报告语言选项选择简体中文（保留用户已有语言偏好，不静默重置为中文）。检查报告仅覆盖本次有证据的项目、图卡日期正确，并在历史记录重开核对数字未变。旧报告正文不会自动重写，缺少历史 visuals 时不会从当前数据补画。
