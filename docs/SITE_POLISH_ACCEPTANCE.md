# 本地页面与数据获取修复验收（2026-10-26）

## 发现与修复

1. 模型配置：使用现有密钥只读请求 `/models`，返回 `deepseek-flash` 和 `deepseek-v4-pro`，原配置 `deepseek-v4-flash` 不在列表中。同步官方模型列表文档（https://api-docs.deepseek.com/api/list-models/），将普通分析默认模型和本机环境配置改为 `deepseek-flash`；旧 reasoner 默认也改用可用模型。历史 canary/计价账本未自动改写，不能把旧模型价格视为新模型已验证价格。
2. 普通报告同步请求关闭隐藏思考，最多输出 4096 tokens，可用 `DEEPSEEK_ANALYSIS_MAX_TOKENS` 配置；截断响应不再作为完整报告返回。普通流式聊天也显式关闭思考，专用 reasoner 流程仍保留其思考行为。没有增加自动重试。
3. 四个维度全失败时跳过无证据综合调用，metadata.report_status=unavailable、partial=true；仍可保存诊断结果。页面显示未生成有效报告，不将失败说明包装成有效结论。历史失败状态和子报告提示中文化，四个维度都不再由分析失败推断原始数据缺失。
4. 公司页历史财务原来仅从 debug 快照构造模块列表，正常模式未请求该快照，导致 history 成功仍不展示。现在直接将实际 history 模块映射到现有组件，不编造值或提高服务端验证状态。
5. 公司页 30 秒加载上限取消待处理请求、忽略迟到结果、停止骨架并保留已返回内容。年度/季度请求不再互相错误作废；旧请求结束不会清理新请求的计时器。默认加载近 5 年，可显式切换全部可用历史，缓存按范围区分。超时不代表服务端同步第三方线程已终止。
6. 导航中等宽度换行分区，链接保持单行，账户名有最大宽度；google_随机用户名显示普通用户标签，原标识可在标题提示中查看，不修改数据库用户名。
7. 热门股操作列保留 table-cell，仅内部按钮容器使用 flex，解决行边框错位。行业快照展示实际交易日期和非实时说明，避免与当前报价混淆。
8. 公司盘后数字最多两位小数，multiple 显示倍、CNY 显示元，保留每项截至日期和来源。公司官网补齐缺失协议，只接受 HTTP(S)，避免跳转成本地相对路径。
9. 额外真实数据缺陷：新浪字段 8 原单位为股，原适配器再次乘 100。公开 sh600186 响应原数量 83,790,350、成交额 797,136,996，平均成交价 9.513 元，与当日 9.31–9.67 元区间吻合。去掉重复乘法；CN K 线兜底报价则按行情契约将手转换成股，HK 保持股。旧报价缓存最多沿用原有短 TTL，未清空共享 Redis。
